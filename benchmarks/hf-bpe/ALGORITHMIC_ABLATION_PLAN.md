# 六个无损算法候选的统一消融

## 范围与基点

用户批准本轮实现永久边界、延迟出生、按需计频、位置批次证书、热冷初始化与末批跳过。语料压实和 grammar/DAG 共享另开实验。本轮从已推送的 `48223a58` 派生，工作树为 `bpe/permanent-boundaries`。

所有候选保持完整有序 merges、每次选中的 pair/频率/输出 ID 和最终 vocab 一致。继续使用权重降序区间、统一 Bulk(4) 与当前 posting arena。私有开关用于同二进制对照，不增加公开 API。非空 affix 保留 HF cohort 路径；依赖平坦地址的候选只在原平坦内核内启用。

## 先实现并检查的协议

1. 永久边界：初始低频 pair 全局汇总后标记；旧 pair 退役时，在本批完成改写后的语料中过滤其 posting，仅标记仍存活的旧边界；低频出生先全局汇总，再标记新边界。下一批 prepare 跳过这些边的出生和扣减。每个原字符边界一位，atomic OR 避免不同 owner 的同字冲突，阶段 join 保证后续可见。
2. 按需计频：未再次精确化的旧频率是上界。只在其可能胜出时过滤 posting、精确求加权频率并重新比较完整 canonical 优先级。记录新增检查位置、无效位置与目录容量。
3. 延迟出生：必须同时保存完整 witness 和一个可与全局完整优先级比较的上界；隐藏状态展开前不能接受可能被其击败的候选。生命周期、重复 witness 与 AA 的活边界识别纳入协议验证。
4. 位置证书：继续取全局连续前缀，符号冲突时才认证全部有效 token 跨度不相交；拒绝后立即截断。AA 和预留 ID 保留单规则处理。记录认证访问和实际放宽次数。
5. 热冷初始化：按物理字符频次选择热字符；热 pair 使用直接目录，冷边仍用 radix，恢复 canonical key 和有序 posting。额外扫描、直接目录及热位置缓冲计入完整耗时与内存。测量 256/512/1024 个热字符的物理边覆盖。
6. 末批跳过：最后的完整前缀已精确认证、分配 ID 和写入 merges，若已达词表目标，则省略其 prepare/rewrite/commit。保持 posting/arena 释放不变量。

## 永久边界证明

普通路径的首次激活定理见 `PAIR_MONOTONICITY.md`。令一个未被删除的物理边界在一轮前的两端为 A、B。一侧合并时，新 pair 的一端含首次激活的身份，它的全部出现只能来自唯一旧邻边的一部分。两側同时合并时，同一最终 pair 的唯一旧邻边是左规则的末 token 与右规则的首 token，仍是子集关系。非负权重下，新 pair 的完整频率不超过旧邻边的合并前频率。若两側均未变化，旧 pair 的频率仅下降。

沿物理边界归纳，某时刻对应 pair 的完整频率低于门槛，以后跨该边界的 pair 均低于门槛。长度门控只会删候选，不会增加频率。预留 ID 首次在语料中激活，满足同一证明；非空 affix 不满足该身份条件，保留原路径。

本批扣减后的旧频率不能约束本批已变化边界的新 pair，因此退役标记必须在改写后检查旧 pair 是否仍实际匹配，出生则独立完成全局汇总。原始字符地址只合并不拆开，未消失边界的地址恒定，位图按其右端原字符坐标索引。

## 验证与最小测量预算

先运行实质协议测试与完整轨迹差分，再冻结提交和 release 二进制。所有实现完成后，按用户要求由一个 GPT 6 Luna 负责正式消融；父代理不同时运行编译、测试或性能解析。

最小正式预算：中文 512 MiB / 4 线程与英文 16 MiB / 4 线程，各测同二进制基线、六个单项和完整组合（8 次）；先用小语料检查各开关模型。若完整组合含明确负收益项，以有据的子组合追加关键对照。最终候选与未修改 `48223a58` 系列冻结二进制比较，至少检查英文单线程；只有具体小差异、组合风险或异常才追加反序对照。所有排序、认证、展开、位图和重算成本包括在 train 内。

保存实际源码、覆盖层、Cargo.lock、二进制/输入/模型 SHA256、完整阶段、操作计数、RSS 与目标 VmSwap。最低可用内存须不少于 1 GiB，所有 posting 生命周期检查通过。收益不可按单项相加，也不把批数或操作数的减少直接换算为时间收益。

## 已完成的实现与正确性检查

六项已接入独立私有开关，生产默认仍是原基点策略，消融后再选择默认组合。

延迟出生原型立即计算全局出生频率作为 canonical 上界，推迟链节点、最终 posting 和 owner entry；用去重的物理边界 witness 覆盖缺失状态，用另一位图记录已消失边界。上界可能胜出时展开全部存活 witness，重新精确计数并排序 posting。该原型不是按父集合拆分的局部延迟同步；其全量展开与两张位图的成本必须由消融决定。

按需计频原型以整张旧账本的上界作为对照，可能胜出时精确求频，并使本轮再次比较复用精确结果。它用于测量冷维护能省多少工作，并未预先宣称热冷混合一定获益。新增记录包括重算 candidate 数、历史 posting 检查数、无效位置数及缓存目录容量。

新位置证书只认证有效 token 跨度，仍使用完整 canonical 全局前缀。最终批跳过不改变该前缀的选择和模型生成。热冷原型以物理字符频次选热集合，用直接 bins 和空间有序片段生成 posting，冷边保留 radix。

完整库测试 75 项通过，0 失败。新增组合差分在 64 组加权语料上核对全部 64 种开关组合，共 4,096 次配置对照，逐轮 pair、频率、ID、有序 merges 和 vocab 与原 HF 一致。另覆盖 AA、零权重、预留 ID、非常小的长度门控、全 u16 初始 ID、宽 u64 权重及 1/4/32 worker；posting 生命周期检查通过。

`posting_visits` 保留历史的选择阶段统计口径；`prepared_posting_visits` 记录实际 prepare 检查的 posting 位置，剔除被跳过的最后一批。`stale_posting_visits` 现实际记录匹配过滤掉的位置，不把 AA 的左到右奇偶排除算作 stale。

## 本轮以外的新方向

最新整理新增：紧凑事件直接填最终 posting、按左字符分区的右字符目录、不可变初始位置区间索引、合并初始化重复扫描、有证书的 affix 快路径，以及按区域遍历与共享位置子集。它们与本轮六项有接口或状态重叠，但尚未实现或验证收益；依用户确认，先完成六项消融，压实与 grammar/DAG 继续留待后续。

## 最终选型

统一消融已完成：8 次小语料检查、16 次英中正式矩阵、2 次未修改基线、2 次中文相邻复测和 2 次英文单线程对照，共 30 次原生训练。模型、线程与布局、posting 生命周期和资源检查均通过。完整记录见 `ALGORITHMIC_ABLATION_REPORT.md` 和 `results/algorithmic-ablation/analysis.json`。

所测六项原型没有建立可稳定优于 `48223a58` 的统一组合。末批跳过首测的优势在中文相邻复测中反转；按需计频和延迟出生的负结论分别限于全冷上界、全局 witness 展开原型。保留此前已推送生产策略。冻结的源工作树仍保持 `9d81ffb1`，各开关可用消融构建器复现；本轮不启用新的生产默认。
