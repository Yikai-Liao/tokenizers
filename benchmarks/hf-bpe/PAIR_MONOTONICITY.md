# 普通 BPE 的旧 pair 频率单调性

## 结论与适用范围

普通、无 dropout 的 BPE 中，一个 pair 在出生轮的全部合并完成后，其真实加权频率在后续轮次中只会下降或保持不变。这个结论不要求每轮分配新的数字 ID；合并后的底层字符串相同，必须复用同一个 token 身份。

本证明使用以下条件：

1. 初始词内 token 是单个 Unicode 字符；alphabet filtering 后，以保留下来的字符序列为准。
2. 一个 token 的字符串等于它覆盖的初始字符序列；合并结果是左右字符串的直接拼接。
3. 每轮在全部词中，从左到右合并选中的 pair，无 dropout，也不按出现位置选择性跳过。
4. Token 只合并，不拆开；词权重非负，计数没有整数溢出。
5. 在整轮所有出现位置处理完毕后比较频率。出生轮内的部分累计值不满足此结论。

`special_tokens` 可以预先占用长字符串的 ID。HF 的训练初始化仍逐字符处理词，不把这些长字符串作为初始原子。因此，ID 已分配与身份已在语料中出现是两件事。

当前代码在 prefix、suffix 均为 `None` 或空字符串时启用证明支持的优化，包括有限 `max_token_length`。有限门控的证明见下节；非空 affix 的可扩展条件另见 [AFFIX_PRUNING.md](AFFIX_PRUNING.md)。

## 定义

每个当前 token 覆盖其词的初始字符序列中的一个连续区间。合并只删除区间之间的边界，不会增加边界。

一个 token 身份“已经激活”，指它曾在任意训练词中实际出现。仅在词表中预留的 ID 不代表已经激活。

## 引理一：边界隔离与独立重放

若一个字符区间 I 的两侧边界在前 t 轮中始终存在，将 I 独立作为一个词，按相同顺序重放这 t 轮合并，得到的分词与完整语料中 I 的分词相同。

证明按轮次归纳。初始时两者都是相同字符序列。假设本轮开始时内部序列相同。完整词中不能有跨越 I 外侧边界的合并，否则该边界会永久消失，与前提矛盾。因此，本轮在 I 内的从左到右扫描与独立扫描一致。

对于可能重叠的 `(A,A)`，外部扫描也不能改变内部配对起点：若区间外的 A 消耗内部第一个 A，就已经跨越左边界；否则扫描从内部第一个未消费 token 开始，与独立扫描相同。右边界同理。归纳成立。□

## 引理二：合并结果必定首次激活

本轮选中的相邻 X、Y 合并得到字符串 s=X∥Y，则 s 不可能是此前已经激活的身份。

取这两个 token 的覆盖区间 I。I 的外侧边界现在存在，所以历史上也始终存在。由引理一，独立重放 s 的字符序列，在本轮开始时应得到 X、Y 两个 token。

假设 s 此前已激活：

- 若它是初始字符，其字符长度为 1，而 X∥Y 至少覆盖两个初始字符，矛盾。
- 否则，在产生 s 的更早轮次，对当时的覆盖区间应用引理一，独立重放 s 在那轮结束时已经成为单个 token。后续规则不能拆开这个 token，因此本轮开始时仍是一个 token。

后者与独立重放得到 X、Y 两个 token 矛盾。故 s 必定首次激活。□

这里证明的是首次出现在语料中，不是首次分配数字 ID。若 s 作为 special token 已有 ID，首次产生 s 时使用该 ID，证明仍成立。

## 定理：旧 pair 不增频

令本轮 replacement 身份为 Z。由引理二，Z 在本轮开始前从未出现在语料中。

一次局部合并删除选中边及相邻旧边，只可能新增 `(L,Z)`、`(Z,R)` 这样的边。每条新增边都含首次激活的 Z，所以相应 pair 不可能在本轮之前存在。

对任何此前已出生的 pair q，本轮只能删除它的出现，不会新增出现。非负词权重下：

```text
C_after(q) <= C_before(q)
```

归纳至后续各轮，得到出生轮结束后的频率单调性。□

本轮新 pair 可以因多个出现位置的出生而累计增频，也可能因本轮后续合并再次扣减。必须先聚合整轮正负变化，才能判断它是否低于阈值。

## 与 HF 候选词集合和频率账本的关系

上述引理先证明全局应用合并的抽象算法。HF 的候选词集合实现可再按轮归纳，避免预设其合并已经全局覆盖：

1. 初始化时，每个 pair 的唯一候选覆盖它出现过的全部词。
2. 假设此前各轮已经全局应用，则下一轮 replacement 首次激活。
3. 本轮新增 pair 都是首次出生，通过本轮的正变化聚合得到一个候选词集合，覆盖其全部出生位置所在的词。
4. 后续旧 pair 无新增出现。因此，其集合始终覆盖剩余出现；弹出该候选并扫描这些词，就是全局应用该 pair。

由此归纳闭合。

HF 的 `Word::merge` 不扣除选中边本身，只报告两侧邻边变化。需要区分其账本与真实频率：

- 尚未选中的 pair，其账本等于真实加权次数，出生后只会下降。
- 已选中的 pair，账本可能留下正值；但唯一候选已经弹出，之后没有正变化使它重新入堆。

所以选中 pair 的残留账本不会使它复活，也不能作为旧 pair 增频的证据。上述等价以计数未溢出为条件，不覆盖 HF 原 i32 账本溢出后的行为。

## 有限长度门控仍允许普通路径

普通字符串身份唯一确定正文字符跨度，因此 HF 的新邻边条件 `len(left)+len(right)<max_token_length` 对同一个 pair 的全部出现具有相同结果。该条件只控制新 pair 是否登记，不在执行已选规则时逐位置跳过合并。

初始化的字符 pair 全部登记，即使不满足长度条件；这是 HF 的初始例外。这些 pair 两端都是单字符，而之后新出生的 pair 含跨度至少为 2 的 replacement，所以新出生的 pair 不会与初始例外重名。

按轮归纳：初始化候选覆盖全部出现；已登记的新 pair 在出生轮覆盖全部出现，其后只能减频。因此每条实际选中的规则仍在全部匹配位置执行，边界隔离与首次激活证明不变。未通过门控的新 pair 不产生候选；HF 对这种边的后续扣减可能留下非正账本，但不会使它被选中，compact 路径可直接忽略。

所以有限门控改变候选集合，不改变已选规则的全局应用，也不破坏旧 pair 单调性。上述论证包括非常小的长度限制及 HF 初始 pair 例外。

进一步的跨度上界、永久阻断边界和无出生内核条件见 [LENGTH_PRUNING.md](LENGTH_PRUNING.md)。

## 合法可达反例：suffix 字符串碰撞

不能将普通定理推广到任意 HF affix。以下反例无需 special token，也不是手工构造的中间状态：

```text
corpus = {"baaba": 1}
prefix = None
suffix = "a"
min_frequency = 1
```

Alphabet 按字符排序，得到 `a=0`、`b=1`。词尾 a 加上 suffix 后是字符串 `aa`，分配 `aa=2`。

```text
初始词：[b, a, a, b, aa]
```

| Pair | 初始次数 |
|---|---:|
| `(a,a)`，ID `(0,0)` | 1 |
| `(a,b)`，ID `(0,1)` | 1 |
| `(b,a)`，ID `(1,0)` | 1 |
| `(b,aa)`，ID `(1,2)` | 1 |

同频时 HF 按 ID 字典序选 `(a,a)`。其拼接字符串也为 `aa`，复用已在词尾出现的 ID 2：

```text
[b, a, a, b, aa] -> [b, aa, b, aa]
```

已入表 `(b,aa)` 的真实次数和 HF 账本都从 1 增至 2。词尾的 `aa` 覆盖一个原始字符，内部的 `aa` 覆盖两个原始字符；字符串身份仍唯一，但已不能唯一确定原始字符序列。这破坏了引理二使用的前提。

因此，结论是某些 suffix 可以破坏单调性。对受限的边界标记或可逆装饰能否扩展证明，需要另外证明其身份映射及合并闭包；不能仅凭 suffix 非空断言必定失败。

此前 `lifecycle_tests` 中的人工别名状态只用于检查通用索引和 HF 账本处理，不能作为普通 BPE 的可达反例。现在代码明确标注这一点，并新增上述真实初始化轨迹的回归测试。

## 本次代码使用的优化

路由位于 [indexed.rs](../../tokenizers/tk-train/src/trainers/bpe/indexed.rs)，当前紧凑内核位于 [compact.rs](../../tokenizers/tk-train/src/trainers/bpe/indexed/compact.rs)。

- 初始计数和每轮出生计数全部聚合后，低于 `max(1,min_frequency)` 的 pair 不再保留候选、posting 和账本记录。
- 被永久删除的旧 pair 后续只有负变化；对其缺失账本的负变化可直接忽略。
- 旧 pair 扣减到低频时永久删除，缺失记录直接跳过；延迟校正候选只更新频率，不复制 posting。
- 每 ID 的长度表用 0 显式记录尚未激活；初始语料中的身份置为 1。命中预留 ID 时，首次激活直接写入合并跨度，不分配出现位置跨度表、不切换到词扫描。
- 无前后缀的路径断言不存在已激活身份的再次出生，包括有限长度限制。通用路径保留原来的完整频率、历史候选和跨度处理。

`monotone_pairs` 统计是否启用该路径，`pruned_pairs` 统计被剪掉的 pair 记录。本定理支持这些优化；完整精确批次仍需要独立证明规则冲突、优先级和出生 pair 的频率上界，不能仅凭单调性宣称批次算法正确。

本证明由独立 subagent 推导，代码使用条件和实现经同一 subagent 只读复核。新增定向测试覆盖全局出生计数聚合与 suffix 增频反例；现有逐轮 HF 差分仍检查 pair、频率、输出 ID 和最终模型内容。
