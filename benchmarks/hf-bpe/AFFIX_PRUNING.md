# 固定 prefix/suffix 的剪枝证书

这是用户要求的独立 subagent 数学推导结果。下面的 affix 证书尚未接入实现；当前代码仍仅对空 affix 使用 compact 内核。普通字符 BPE 与有限长度门控的证明见 [PAIR_MONOTONICITY.md](PAIR_MONOTONICITY.md)。

## 固定装饰保留的结构

令 A 为训练时保留的正文字符 alphabet，P 为 prefix，S 为 suffix。每个 token 始终可写为 `P^h x S^e`，其中正文 payload `x∈A+`；h 表示区间不含原词首字符，e 表示区间含原词末字符。合并右端必带 P，左端必不带 S，所以 HF 剥离右端一次 prefix 后得到相同形式。

同时 h=0、e=1 的 token 已覆盖整个词，是孤立 token。参与 pair 的类别只有：

| 类别 | 字符串形式 |
|---|---|
| 首部、非末尾 | `A+` |
| 续接、非末尾 | `P A+` |
| 续接、末尾 | `P A+ S` |

alphabet filtering 不改变这里的装饰规则：flags 仍按原字符位置决定，A 则取实际保留的正文字符。

## 证书一：pair 单调

充分条件：**每个非空 affix 都至少含一个 A 之外的字符**。空 affix 忽略。

这使上述参与邻边的类别在其 flags 有区别时互不冲突，且正文 payload 可唯一恢复。对规则轮次归纳：候选覆盖所有剩余出现；同一个 pair 的正文跨度一致，长度门控结果一致；全局应用选中规则后，边界隔离重放排除 replacement 在相同邻边类别中曾经生成。

replacement 可能复用此前整个词的孤立 token ID，但此前该孤立出现没有邻边；新产生的相关 pair 仍首次出生。若 replacement 本身覆盖整个词，它也不会新增邻边。因此旧 pair 只能减频，可以在整轮聚合后永久剪除低频 pair。

这个条件允许两个 affix 使用同一个 marker、重复 marker 或相互包含。special token 只预留 ID，不影响论证。

## 证书二：统一 ID 跨度与首次激活

pair 单调证书还不足以直接使用当前 compact 的每 ID 长度表。四种装饰形式仍可能发生 `P x = y S` 冲突：

```text
A = {a}, P = "aa#", S = "#a"
P + "a" = "aa" + S = "aa#a"
```

左侧正文跨度为 1，右侧为 2；右侧是孤立整个词，所以不破坏 pair 单调，但破坏统一 ID 跨度。

以下强条件可以直接排除全部冲突：

```text
P 为空，或 P 的首字符不属于 A
S 为空，或 S 的末字符不属于 A
```

通过后，可唯一恢复 flags 和 payload，边界隔离重放恢复身份首次激活证明，可使用紧凑跨度表及有限长度限制。仅有一个非空 affix 时，其中任意位置含正文外字符就已足够。

### 更宽的精确冲突检查

在每个非空 affix 含正文外字符的前提下，分解 `P=α U β`、`S=γ V δ`。α、β、γ、δ 是最大正文字符前后缀，U、V 从首个正文外字符延伸到最后一个正文外字符。

存在上述唯一类型的冲突，当且仅当以下三条同时成立：

1. `U=V`。
2. α 以 γ 结尾，且 α 比 γ 长。
3. δ 以 β 开头，且 δ 比 β 长。

冲突 payload 唯一：y 是 α 去掉末尾 γ，x 是 δ 去掉开头 β。这是 affix 长度线性复杂度的静态检查。没有冲突时，四类装饰可逆；有冲突时仍可使用 pair 剪枝证书，但须保留出现位置跨度处理。

## 正文内 marker 确实需要 fallback

suffix `"a"` 与 `{"baaba":1}` 的完整反例见普通证明：合并 `(a,a)->aa` 使旧 `(b,aa)` 从 1 增至 2。

prefix 单独存在也有可达反例：

```text
P = "ab", S = None
corpus = {"aba":2, "abaa":1, "bbaa":1}
a=0, b=1, abb=2, aba=3
```

初始 `(a,abb):3`、`(b,abb):1`、`(abb,aba):4`、`(aba,aba):2`。先选择 `(abb,aba)->abba=4`，旧 `(aba,aba)` 降到 0；再选择 `(a,abba)->aba=3`，`abaa` 变成 `[aba,aba]`，旧 pair 从 0 增到 1。

## 即使全局证书失败，仍可局部剪枝

未来合并输出的正文跨度至少为 2。可能成为 pair 左端的输出只属于 `A+` 或 `P A+`；右端只属于 `P A+` 或 `P A+ S`。

对每个 ID 尝试相应装饰剥离，检查 payload 是否至少两个字符且全部属于 A，得到 `may_merge_into_left(id)`、`may_merge_into_right(id)`。若 pair `(u,v)` 满足两者分别为 false，未来合并不可能重新生成该 pair；其账本低于阈值后可永久删除。

仍须遵循 HF 账本：不能仅因真实出现为零就删除尚有正账本和历史 cohort 的候选。

## 实现取舍

完整可逆证书最适合优先扩展路由：一次初始化检查后可以整体使用 compact。仅 pair 单调或逐 pair 输出角色证书则需要把剪枝、首次激活断言、统一跨度三个条件拆开。当前没有为这些候选优化添加实现或性能测量。
